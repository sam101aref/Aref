# Arash The Archer — فهرست ویژگی‌ها و نقشهٔ راه

اولویت‌ها:
- **P0** = لازم برای MVP (اولین نسخهٔ قابل‌بازی روی گوشی)
- **P1** = لازم برای نسخهٔ انتشار (v1.0)
- **P2** = بعد از انتشار

هر ویژگی یک شناسه دارد (مثلاً `F-01`) تا بتوانیم یکی‌یکی سراغشان برویم. وضعیت: 🟡 = کد نوشته شده، منتظر اولین ساخت و تست روی گوشی · ✅ = تست‌شده و تمام.

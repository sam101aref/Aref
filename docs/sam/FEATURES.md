# Sam Nariman — فهرست ویژگی‌ها و نقشهٔ راه

مثل آرش، هر ویژگی یک شناسه دارد (`S-01`…) تا یکی‌یکی جلو برویم.
وضعیت: ✅ = ساخته و با تست خودکار بازی شده · 🟡 = ساخته شده، منتظر تست روی گوشی واقعی · ⬜ = هنوز ساخته نشده

اولویت: **P0** = نسخهٔ قابل‌بازی اول · **P1** = نسخهٔ انتشار · **P2** = بعد از انتشار
